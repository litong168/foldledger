## 二、软件说明书（用户手册，登记可选但强烈建议一并提交）

建议整理成 20-40 页 PDF，结构如下：

### 1. 概述
滴水记账 V9.0 是一款运行于 Android 设备的**纯本机**个人记账工具。全部数据以 SQLite
存储于设备本地，应用不申请网络权限、不设账号体系、不内置广告与统计 SDK，隐私数据不
出设备。软件支持多账本与场景模板、流水记录与多维筛选、预算与周期记账、报销垫付与
回款跟踪、统计分析与消费日历、智能洞察、回收站与自动备份、导出与恢复，并提供
"一句话记账"与"记账助手"等提效功能。

### 2. 运行环境
- 操作系统：Android 8.0（API 26）及以上，目标 API 35
- 硬件：ARMv7 / ARM64，2GB RAM 以上；支持折叠屏形态切换
- 开发环境：JDK 17、Gradle 8.13、Kotlin 2.0.21、Jetpack Compose、Room 2.7、Rust stable

### 3. 安装与启动
从应用商店或安装包安装；首次启动进入账本页，可直接创建账本或从场景模板一键创建。
应用采用液态玻璃视觉语言，适配深色/浅色主题与动态取色。

### 4. 功能模块
| 模块 | 功能说明 |
|------|----------|
| 账本管理 | 多账本、场景模板（日常/装修/报销/育儿/车/住房/旅行/宠物）、预算、归档、删除回收站（可恢复） |
| 记一笔 | 金额、分类、账户、项目、报销状态、场景自定义字段；支持数字键盘与触感反馈 |
| 一句话记账 | 自然语言输入解析金额/日期/方向/分类，实时预览后入账，可撤销；分类建议从历史学习 |
| 流水管理 | 按日分组、多维筛选（分类/账户/项目/报销状态/日期区间）、搜索、批量改账、批量移账 |
| 报销 | 垫付/待提交/已提交/已到账四态；账龄四档与催办摘要一键复制；项目级看板 |
| 周期记账 | 周期模板、下次到期提醒、到账入账 |
| 资产账户 | 多账户、初始余额、净资产计算、账户级流水 |
| 统计与洞察 | 月度/年度统计、预算健康度、消费日历热力图、智能洞察（周期识别/净资产走势/趋势预测） |
| 记账助手 | 今日待办（未记账/自动记账待确认/垫付超期/预算红线/周期到期）+ 智能建议 |
| 自动记账 | 支付通知与银行动账短信解析，条目进入"自动记账"账本待人工确认移入正式账本 |
| 备份与导出 | JSON 可恢复备份、Excel 可阅读导出、SAF 目录自动备份、回收站恢复 |
| 折叠屏适配 | 覆盖态/展开态/桌面态/书本态四种形态，展开后双栏布局 |

### 4. 操作流程（配截图）
账本创建 → 记一笔 → 分类与账户设置 → 预算与周期 → 报销登记与催办 → 统计查看 →
导出备份与恢复 → 回收站恢复。

### 5. 数据与安全
本机 SQLite 存储；删除账本进回收站可恢复；备份文件由用户自行保管；应用无网络通信能力。

## 四、申报流程（中国版权保护中心）

1. 账号：中国版权保护中心官网注册（个人实名 / 企业需证照）
2. 填报：在线填写申请表（字段见第一节）
3. 上传：源程序文档 PDF + 用户手册 PDF + 主体证明文件（营业执照副本加盖公章 / 身份证）
4. 缴费与受理：受理后进入审查，通常 30-60 工作日下发证书（可咨询加急通道）
5. 拿到证书后：小米开发者平台「应用资质 → 计算机软件著作权证书」处上传

> ⚠️ 名称一致性是硬要求：**证书上的软件全称 = 备案名 = 上架名**，不一致会被驳回。
> 建议软著全称就用"滴水记账记账软件"，上架名"滴水记账"，并在填报前确认平台是否要求完全一致
> （小米 FAQ 明确：应用名称、软著名称、APP 备案名称应一致；如不一致需按官方指引统一后再提交）。
