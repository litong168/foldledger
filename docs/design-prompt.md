# 滴水记账 · 视觉提示词 v13.9

> 这是"给 AI 或给人看的设计指令"，不是文档。每一条都带**可验证的数值**，
> 因为 v13.0 → v13.2 三轮失败的原因都不是"审美不对"，而是**参数之间互相抵消**：
> 白膜压在白底上、冷光盖住暖底、语义色压到 3.6:1 —— 单看每一条都合理，
> 叠起来就是"一片灰"。
>
> v13.9 起背景改为**静态三段色温 + 颗粒**（四团漂移环境光已整层退役），
> 呼出层统一走 `GlassDialog` / `GlassMenu`，小控件统一走 `glassChip`（见 §4.5）。

---

## 0. 一句话

**浅色暖纸上的液态玻璃：卡片比底略白、边缘弯折背景、文字比想象中更深、彩色只用来分状态。**

---

## 1. 三条硬门槛（发布前必须量，不许目测）

| 项 | 下限 | 量法 |
|---|---|---|
| 卡片 / 背景 明度对比 | **≥ 1.10:1** | 截图像素，`(L卡+0.05)/(L底+0.05)` |
| 语义色（收/支/待处理）压在所在底上 | **≥ 4.5:1** | WCAG 相对亮度 |
| 三级文字（日期/笔数/单位） | **≥ 4.0:1** | 同上；低于 3:1 属于"看得见但读不出" |

> v13.2 三条全部不达标（1.02 / 3.61 / 2.66），所以被用户判为"易读性差、太灰"。
> **对比度不是审美偏好，是可用性底线。**

## 2. 底色与环境光

### 2.1 底面必须是三段色温，不能是平涂

| 位置 | 亮色 | 说明 |
|---|---|---|
| 顶 0~22% | `#F3F6FA` 混入 80%→28% | 极淡冷白，"天光" |
| 中 55% | `#EDEAE3` | 暖米白，纸的体温 |
| 底 82~100% | `#E3DACB` → `#D8CDBA` | 砂影，把"上面有光"坐实 |

- 人眼判断"灰"靠的不是饱和度，是**同一屏里有没有两种色温**。
- 顶部提白**不超过 30%**：超了会把标题与首屏卡片那一带推成惨白，而那正是最需要分层的地方。
- 暖底上压沉只能用**暖墨**（`#4A443B` 级），压冷灰会在底边泛一条发青的脏边。

### 2.2 环境色光已退役（v13.9）

v13.9 把四团漂移色光（雾蓝 / 藕荷 / 薄荷 / 极浅桃）**整层删除**，背景只剩三段色温 + 2% 颗粒。
删因：① 单帧认不出是光，要"盯着看三秒"才存在的装饰性价比为负；② 暖底 + 冷光对冲 = 中性灰，
正是"整体太灰"的源头之一；③ 4 次全屏径向渐变 × 120fps、永不结束的 InfiniteTransition；④ 开关只改"动不动"。
**别再把这层加回来。** 保留这条是给后来人看的教训：

- ⚠️ **超过 30% 它就不是"光"，是一层颜料。** v13.2 用了 0.98，设定的暖底被压成冷蓝灰
  `#DCE3E7`，改三个版本底色都看不见 —— 因为底一直被盖着。
- 暖 : 冷 的比例 **≥ 2 : 1**；1 : 1 会中和成中性灰，这是"太灰"最常见的成因。

### 2.3 暗色

- 底 `#15171C`（炭灰 + 极微弱冷蓝），**不用纯黑**：纯黑没层次，6.5% 白膜的卡片会塌进背景。
- 暗色的"更实"是**更深**，不是更白。

### 2.4 动态取色（Material You）只能换强调色

`dynamicLightColorScheme()` 在 M3 标准应用里是对的，在**这一套材质里是反作用**：

| 它想换的 | 换掉之后 |
|---|---|
| `background` | 底色是三段色温渐变（§2.1）+ 四团色光，`base` 一换整条曲线跑偏 → **§1 的 1.10:1 与 暖:冷 ≥2:1 同时失效** |
| `surface` / `surfaceVariant` | 玻璃膜 / 影 / 折射带的 alpha 全按"近白亮底"标定，换中明度底后人影环和上沿白棱都不成立 |
| 语义色 | 豆沙红 / 收入绿 / 待处理棕是**记账语义**，不是装饰 —— 用户认的是"这个红是支出" |

所以**只让它换 `primary` / `onPrimary` / `primaryContainer` / `onPrimaryContainer`**：
按钮、进度条、选中态、图标跟着壁纸走，底色与材质不动。这是"能用且不毁材质"的唯一一条边界，
再往外扩一步就会撞上面三行。

### 2.5 那层 2% 颗粒不是"纸纹"

v11 的纸面肌理在 v13 整层删掉了。现在剩下的 `dither` 颗粒（亮 2.0% / 暗 3.0%）
**作用是消除渐变色带**（OLED 上大面积低对比渐变会出现台阶），不是质感 ——
所以它是**静态且常开**的，不受任何开关控制。

⚠️ v13.9 起连「环境光晕」这个设置项也删掉了 —— 背景已是静态，没有可开关的动态层。
（历史：那个开关曾控制四团色光要不要漂移，v13.9 连那四团光一起退役，见 §2.2。）

## 3. 玻璃材质（亮色 / 暗色）

| 层 | 亮 | 暗 | 作用 |
|---|---|---|---|
| 膜（卡片） | 白 **17.5%** | 6.5% | 只负责"这里有一层介质" |
| 膜（流水行） | **18.5%** | 5.8% | 行矮但**必须比卡片实**（见下方规则 5） |
| 流水行投影 | **1dp** | 1dp | 只当轮廓用，不是"浮起" |
| 流水行缝隙 | **3dp** | 3dp | 一屏十几行时 5dp 会成斑马纹 |
| 膜（面板/浮条） | 10.5% | 5.2% | 面积大 |
| 膜上下落差 | ×1.28 / ×0.55 | 同 | 写反 = 塑料片 |
| 体色温 | 左上冷 3% / 右下暖 2.4% | 2.2/1.6% | "光穿过介质色温变了" |
| 曲面反射 | 5.2% | 3.8% | 圆心 28%/0%，半径 0.92 宽 |
| **折射带** | 5dp，**15.5%** | 5dp，10.5% | 4 道同心内缩描边 `[1,.62,.30,.10]` |
| 内侧暗线 | 整圈 4.2% / 底 8.5% | 5% / 13% | 白棱的衬底 |
| 虹彩 | 3dp，**只左上 205°~250°** | 同 | sweepGradient 限角 |
| 白棱 | 1.1dp，上左 96% | 84% | 最锐的一层 |
| 投影 | ambient 7.8% / spot 10.5% | 24 / 28% | 系统 shadow，绝不手画 |

**四条不能破的规则**

1. 折射带必须是**向内衰减的带**，不能是一条 Stroke（Stroke 垂直方向等亮硬收尾 = 描边）。
   小控件（≤24dp）按短边 22% 收窄，否则左右两条带对撞。
2. 虹彩只能 sweepGradient 限角。对角 linear 会让四条边都染色 = 卡片贴彩色边框。
3. 描边一律**内缩半宽**，否则被 clip 切掉一半。
4. 卡内次级控件**不叠白**（白叠白消失），用 `wellSurface()` = 墨 6.5% 凹下去。
5. ⚠️ **系统阴影的 alpha 是常量，不随 elevation 缩。** `Modifier.shadow` 的
   `ambientColor/spotColor` 不论 elevation 多少都用同一个 alpha，变的是扩散半径。
   所以在半透明行上挂 2dp 阴影，那道影会从行面底下透上来，把白膜提亮的几个百分点
   全压回去 —— **行会变得比行间缝隙还暗**（v13.3 实测 #E3E0D9 vs #E7E4DC）。
   **小尺寸玻璃（行 / chip / 键）一律 1dp**：半径贴边，只在轮廓上留一道暗环。

## 3.1 玻璃层的判据（不是所有层都看"面差"）

| 对象 | 判据 | 量法 |
|---|---|---|
| **大卡片**（概览 / 分组） | 面差 ≥ **1.10:1** | 卡内 vs 卡外背景 |
| **流水行** | 边缘成立即可 | 行面与缝隙差 1.03~1.05 就够，真正撑轮廓的是"上沿白棱 + 下沿暗线 ≥ 6 个明度级" |
| **凹槽 / 占比条槽** | 槽 ≥ **11% 墨** | 低于 8% 在暖米白上只剩 1.02，等于没有 |

> 近白底（L\*≈90）上，白膜根本做不出 1.10 的面差 —— 那需要 30%+ 膜，也就是"厚卡"。
> 大卡片靠的是**膜 + 投影暗环**的组合；流水行靠的是**边缘**。别把同一套数字套到所有层上。

## 4. 语义色（亮 / 暗，附实测对比度）

| 语义 | 亮 | 暗 | 亮底对比度 |
|---|---|---|---|
| 支出（豆沙红） | `#96574D` | `#E3B0A7` | 4.72 |
| 收入（薄荷绿） | `#427E68` | `#A8D6C0` | 3.95 |
| 待处理（琥珀） | `#A2733A` | `#D8A462` | 3.15（只用于 11sp+ 或图标） |
| 主色（雾蓝） | `#4A6B87` | `#A6C2D8` | 4.73 |
| 一级墨 | `#17181B` | `#EDEDEA` | 15.0 |
| 二级墨 | `#43464C` | `#ADAFAC` | 7.2 |
| 三级墨 | `#6A6D74` | `#8A8C91` | 4.4 |

- 语义色**必须按主题分档**（`forDark()` / `pendingTone()`）。一个值打天下必然有一半场景不可读。
- 低饱和 ≠ 低对比。豆沙红可以又"豆沙"又清楚：**色相不动，压明度、略提饱和**。

## 4.5 小控件与呼出层（v13.9 新增：glassChip / GlassDialog / GlassMenu）

v13.9 把"一块平涂色片"当**一整类错误**清扫掉了。三个新素材是同一套玻璃语言的分身：

| 素材 | 位置 | 关键参数 |
|---|---|---|
| `glassChip(shape, tint, strength, elevation)` | 小控件：chip / 徽标 / 入口块 / 胶囊 / 日历格 | 语义色进膜，`fill = tint.copy(alpha = 0.13 × strength)`（暗 0.18），`specular = 1.15 × strength` |
| `GlassDialog` | 包 M3 `AlertDialog` | `overlaySurface()`（亮 0.88 / 暗 0.92）+ `filmDepth 0.82` + `specular 1.55` + 22dp 影 |
| `GlassMenu` | 包 M3 `DropdownMenu` | `popoverColor()`（亮 0.975 / 暗 0.985）+ `filmDepth 1f` + `specular 1.6` + 18dp 影 |

**四条不能破的规则**

1. **选中态 = 同一块玻璃的更高浓度，绝不用实色。** 选中 chip 用 `strength 1.9×~2.6×` + 挂 3dp 影，
   未选中 `0.85×`。实色会让边界从"棱"退化成"贴纸边"（用户否过的「实色选中块」）。
2. **选中文字不染语义色。** 膜加到 24% 后底色偏灰，`#4A6B87` 在其上只有 3.1:1 —— 13sp 的字这么写不合格。
   对比交给字重（SemiBold）+ 膜浓度，字一律 `onSurface`。
3. **`glassChip` 面积越大浓度越低。** 150×50dp 的大面 `strength 0.55` 就够（13% 铺上是 `(208,207,207)`
   中性灰板，比下面每行字还重）。面积反比于浓度，不是拍脑袋。
4. **弹层 `filmDepth` 必须压到底。** `GlassMenu` 锁 `1f`（0.7 实测透出背后「筛选/多选」灰字）；
   `GlassDialog` 有 34% 遮罩托底可放 `0.82`。菜单是唯一拿不到背后像素的浮层，iOS 靠降透明度+真高斯，
   我们只剩"不透明度"一根杠杆 —— 98.5% 是"读不出重影"的下限，玻璃感靠边缘白棱+虹彩+内侧暗线，不靠透光。

## 5. 版式

- **字阶只有 8 档**（v13.7 统一，定义在 `ui/theme/Type.kt`）：

  | 档 | sp | 管什么 |
  |---|---|---|
  | Hero | 44 | 首屏唯一的那个大数（一屏只许出现一次） |
  | Display | 30 | 声明性数字：账户余额、速记金额 |
  | Head | 24 | 卡内大金额、sheet 标题 |
  | Title | 20 | 页面区块标题、弹层标题 |
  | Subhead | 17 | 卡片标题、列表主文本加重 |
  | Body | 15 | 正文、流水行主文本 |
  | Caption | 13 | 次级说明、备注、时间 |
  | Label | 11 | overline、chip、轴刻度（**中文的下限**） |

  **相邻两档至少差 1.15 倍。** 统一前全仓有 24 种字号（8/9/10/10.5/11/12/13/13.5/14/
  14.5/15/16/17/18/19/20/21/22/24/26/30/38/40/44）—— 其中 13.5、14.5 各只出现 2 次和
  1 次。1sp 在 440dpi 上只有 2.75px：不足以读成层级，只足以读成"没对齐"。
  **11/12/13 这种三连是这里最容易犯的错。**
  数字一律 `tnum`。校验：`python scripts/check_type_scale.py`（`.sp` 内联 / Int 形参 /
  Int 默认值三条写法都查，发布前必跑）。
- 玻璃上不用 ExtraBold；层级靠**字号差 + 墨的深浅**建立
- 圆角 12 / 18 / 26 / 30 / 36；页边距 20；卡内 18；触控 48dp
- 外壳：顶栏玻璃膜（34%→13% 竖向渐变）、**底栏悬浮玻璃胶囊**（左右 20dp），侧栏已退役
- **底栏 = 三格胶囊 + 一颗独立圆钮**（v13.6）：明细 / 账本 / 我的 三格；
  「记一笔」在胶囊**外**、右侧 10dp 空气处，52dp 深色球 + 20dp 加号（十字占直径 22%）。
  它仍落在 `bottomBar` 槽里，所以照样不覆盖内容。**不要再塞回胶囊当第四格** ——
  三格线条图标配一格实心圆，格宽一样重心不一样，读起来是"胶囊里挤了个异物"。
- 单栏阈值：**≥ 700dp 才分栏**。600~700 是"能分但没一栏能读"的死区
  （608dp 分栏后右栏「¥6,979.71」会截成「¥6,97…」）

### 5.1 首屏预算：非流水内容不得挤掉第三行流水

860dp 高的屏，扣掉系统栏与底栏留白，内容区约 **730dp**。硬指标：
**首屏至少露出 2 行完整流水**（每行 51dp + 日期头 20dp ≈ 71dp/组）。

v13.3 之前，单栏顶部依次叠了六层：
breadcrumb+大标题（76）→ 账本 chips（44）→ 分段（42）→ 概览（40）→ 净资产（16）→
工具卡（33）→ 项目 chips（22），**合计 273dp**，流水只剩 1.5 行。

三条可复用的减法（v13.4 已落地）：

| 手法 | 省 | 判据 |
|---|---|---|
| 摘要类内容**降级为脚注**（去容器、对齐卡内边距、压到 40dp） | 35dp | 只有一行字却占一张卡 = 该降级 |
| **同层操作并成一行**（搜索 + 筛选 + 多选） | 54dp | 都在回答"怎么找"，就不该各占一行 |
| 只在**有信息量时**显示（单月的"占比最高月"细条） | 12dp | 恒为 100% 的进度条不是信息，是装饰 |

v13.7 又砍掉两条，单栏顶部从 **七层降到五层**：

| 手法 | 省 | 判据 |
|---|---|---|
| **大标题写"当前对象"**，切换收进标题下拉，账本 chips 整行退役 | 48dp | 恒定标题是装饰；对象名写两遍是重复 |
| 净资产脚注**没有账户时不渲染** | 40dp | 恒为 ¥0 的一行不是数据，是横幅广告（入口仍在「更多 → 资产账户」） |

⚠️ 净资产、账户余额这类**存量**数据天生是"流量的脚注"：它衍生自流水，
不该和流水平起平坐地各占一层玻璃。对齐卡的左内边距、去掉容器，它就会被读成卡的一部分。

⚠️ **"零值不占位"要配一个仍然可达的入口**。隐藏「净资产 ¥0」是因为它没有信息量，
不是因为它不好找 —— 所以动手之前先确认同一个动作在别处还有入口。

### 5.2 滚动折叠：动的是"非内容的壳"，不是内容

明细页往下滚时，**大标题收成一行**（64→46dp、23→16sp）、**副标题高度收到 0**（18→0dp），
合计再省 **36dp**；回到顶部时逐帧还原。
（v13.5 时还有一条 48dp 的账本 chips 跟着收，v13.7 起 chips 已整体退役。）判据：

| 规则 | 数值 | 理由 |
|---|---|---|
| 折叠进度 | **连续浮点 0→1**，由列表首个可见项的 `scrollOffset / 72dp` 驱动 | 布尔只能淡入淡出，读起来像"换了张皮"；iOS 大标题是"被推上去" |
| 收起的对象 | 只收**导航用的壳**（副标题、大标题、chips） | 分段控件（明细/分类/月份）是视角切换，必须常驻 |
| 副标题 | 折叠时高度收到 0，不只是透明 | 透明仍占位 = 没折叠 |
| 副标题 | 高度 + 透明度**双通道**同收 | 只收高度会"啪"地消失；只淡出会留 18dp 空洞 |
| 翻页 | 切到分类/月份时折叠**归零** | 那两页没有长列表，标题恰恰还要用 |

⚠️ 折叠只改栏高与 chips 行高，**不动 LazyColumn 的首项锚点** —— 否则会"收起→布局变→再收起"地抖。

### 5.3 「记一笔」要在栏内，但不许**长在导航里**

悬浮球（FAB）的问题不在形状，在**它悬着**：一定盖住某一行。v13.4 实测首屏第二行
「-¥216」的末位被圆钮吃掉。所以它必须沉进底栏那条带 —— 但 v13.5 的做法（塞进胶囊
最右格、变第四格）是错的：

- 三格线条图标旁边忽然多出一颗实心圆 + 一行 10sp 文字，**格宽一样、重心不一样**，
  读起来是"胶囊里挤了个异物"；
- 胶囊里从此有四种语义（三个 Tab + 一个动作），横滑映射还得为"多出来的第四格"打补丁。

**v13.6 定稿：胶囊是纯导航（三格），「记一笔」是胶囊外的一颗独立圆钮，中间留 10dp 空气。**
两颗各自完整 —— 不是"一个胶囊被切了一半"。它仍落在 `bottomBar` 槽里，所以依然不覆盖内容。

| 项 | 值 | 判据 |
|---|---|---|
| 圆钮直径 | 52dp（= 胶囊高） | 与胶囊等高才成"一条线"，高一点就成"两颗钮" |
| 与胶囊间距 | 10dp | 更窄会粘成一条，更宽就散开 |
| 加号字形 | 20dp | 十字实测只占直径 **22%**。v13.5 是 16/26 = 61%，圆被撑满 → 突兀 |
| **材质** | **`GlassKey` 玻璃球**（`tint = primary`、`tintBoost = 1.3`、`glow = primary`） | 见下 |
| 加号颜色 | 亮 `lerp(primary, #000, 0.24)` / 暗 `primary` | primary 压在暖砂底 3.86:1、叠 22% 染色后 3.83:1 → 压深到 **4.52:1** |
| 暗色 | 同上，`primary` 直接用 | 暗色 primary 是浅蓝，染在深玻璃上正好是"发光的蓝" |

⚠️⚠️ **主行动键必须是玻璃，不是实心色块。** v13.6 做了一颗实心 `primary` 球，
理由是"主行动必须最沉" —— 那是把"最沉"读成了"最实"。整站唯一的材质语言是玻璃，
一屏玻璃里放一块**不透光**的色块，它读起来不是"更重要"，而是**"这不是这套 UI 里的东西"**：
没有边缘弯折、不随背后色光变化，像贴上去的。v13.8 改回 `GlassKey`。

**玻璃键怎么表达"这是主行动"**（三件事，缺一件就变成普通玻璃）：

1. **染色** `tintBoost = 1.3` → 膜上的主色 17%/11%/13.5% → **22%/14%/17.5%**。
   仍是透明的，但它是这一片里**唯一有色温的玻璃**。上限压在 0.30 —— 超过去就退回"填了一块颜色"。
2. **体积**：球面径向亮心（左上 38%/30%）+ 1dp 白棱（左上 94%）+ 左上 132° 虹彩 + 下缘焦散。
3. **影**：`glow = primary`，投影带主色 —— 落在暖底上是一圈极淡的蓝影。玻璃浮起来才有影。

⚠️ **"更重要"不能用"更不透明"表达。** 透明度是这套材质里唯一不能拿来排序的量：
一旦某块比别的更实，它就不是"更重的玻璃"，而是"另一类材质"。

### 5.4 双栏时底栏停右栏，不许骑在分栏缝上

860dp 横屏双栏：分栏缝在 368dp。v13.5 的胶囊全窗居中，落在 **316~544dp** ——
正好骑着缝，还压住左栏月份卡的末行。读起来像"导航不知道该属于哪一栏"。

**v13.6：`env.twoPane` 时整组（胶囊 + 圆钮）`Alignment.BottomEnd`，贴右栏右下角。**
左栏（列表）底部彻底干净；右栏是「概览 / 详情」，底部本来就空，且它可滚 ——
靠两栏各自的 `bottom contentPadding ≥ 底栏总高` 保证最后一项能滚出来。

⚠️ 判据是**缝**，不是左右。单栏时仍然居中（居中本身没问题，问题是被缝穿过）。

### 5.5 月份页：单月是"月报"，多月是"对比"

同一张月份卡，两套篇幅。判据 `months.size == 1`：

| | 单月 | 多月 |
|---|---|---|
| 日支出柱状图 | 有（横向 31 格） | 有 |
| 分类构成 | 6 条 | 4 条 |
| 单笔最大榜 | **有（5 笔）** | 无 |

单月时下方原本空 35%，补上单笔榜正好填满；多月时每张卡再挂 5 行明细，整页就变成
"一堆要滚过去的长卡"，反而看不出月与月之间的对比。

⚠️ **柱状图不给空日画整高槽**。v13.4 每格先铺一根整高浅灰槽，31 格铺满后那 22 根空槽
是**22 条等宽等高的竖灰线** —— 真机上读起来像扫描线 / 没加载完。v13.6 改成
空日只留底部 3dp 的"墩"，有支出才长起来，整排变成"雨量图"。

⚠️ **小额柱下限 6dp、空墩 3dp**。两者都取 3dp 就分不清"花了 1 块"和"没花"。

⚠️ **刻度必须有**（1 日 / 月中 / 月末）。没刻度时读者不知道横轴是"日期"还是装饰条。

⚠️ **"单日峰值" vs "单笔最大"两个词不能混用**。同一个 15 日，前者是当天合计
¥2,894.81、后者是最大单笔 ¥1,704 —— 只写"最高"就是自相矛盾。

### 5.6 大标题写"当前对象"，不写栏目名

明细页原来是：23sp 恒写「明细」+ 11sp 副标题写账本名 + 下面一整行账本 chips（48dp）
再写一遍账本名。**同一个词一屏出现两遍，而最大的那颗字永远在说同一句话。**

现在：**副标题 = 栏目标签（场景），大标题 = 当前对象（账本名）**，切换收进标题右侧的小箭头。

| 位置 | 内容 | 为什么 |
|---|---|---|
| 副标题 11sp | `🧾 报销` | 栏目/场景 —— 这一类页面都这么说 |
| 大标题 23sp | `报销账本 ⌄` | 变量、有信息量；点它换对象 |
| 下拉菜单 | 每条带 emoji + 账本名 + **结余** + 当前项勾选 | 信息一条不少，只是不再常驻 |

判据三条：

1. **有"当前对象"时，大标题必须写对象**。它不随状态变，就不配占最大的字。
   （账本页 / 我的页没有当前对象，标题就是栏目名，这是合理的 —— 但「明细」页里明明
   有一个当前账本，把它挤到 11sp 副标题去、让「明细」占着 23sp，就是拿栏目名占了对象的位子。）
2. **下拉要严格比上一版多一层**：原来 chips 一点就切，现在点标题 + 点条目 = 两步 ——
   所以菜单里必须把 chips 上原有的信息（结余）补齐，且当前项要有勾。
3. **浮层必须 98.5% 不透**（`popoverColor()`），不能复用底栏那档 92%。
   菜单打开时底下正对着标题和 44sp 大金额，8% 的透光足以让它们变成重影。
   （底栏透是因为它下面滑过的是列表，透一点反而是玻璃的证据 —— 两者不是一回事。）

同一逻辑往下推：**概览卡展开态的"报头"也删了**。它画 头像 + 账本名 + 场景名，
和大标题/副标题逐字重复，却用小一号的字 —— 读起来像标题的残影。收起手柄改挂在
「尚余垫付 / 累计结余」那一行的右端，一个 11sp 的「收起」+ 8dp 内边距撑热区。

### 5.7 项目条：结清的收进抽屉，不删除

报销项目有生命周期：建 → 一堆待提交 → 交单 → 等回款 → 钱回来。
走到**「全部交出去了」**之后，它继续占着项目条最前面，每次看流水都要先划过三四个
已经不想再碰的项目。

**判据：`pendingCount == 0`**（这个项目里没有任何一条还停在「待提交」），或用户手动「已结束」。
为什么不是"已回款"：报销流程里真正需要你动手的只有"待提交"这一步；
单子交出去之后剩下的是等公司打款，那件事在「尚余垫付 / 催收列表」里统一看，
不需要在项目条上一个个占位。

| 项 | 做法 | 判据 |
|---|---|---|
| 位置 | 项目条**末尾**一枚「已归档 N ▾」把手 | 它不是筛选器，是会话内开关；收起只占一枚 chip |
| 展开 | 追加到列表末尾，`dimmed = true` | 归档项必须和"还在办事的"一眼分得开 |
| 删除 | **不删**。流水、归属、金额全在 | 归档 ≠ 删除，语义不同不能合并 |
| 自愈 | 往该项目新记一笔（默认待提交）→ 自动回到进行中 | 判据是算出来的，不是存的字段 |
| 选中 | 当前选中项在归档区 → 抽屉自动展开 | 否则"我在看哪个项目"在屏幕上找不到 |

⚠️ 抽屉把手上的三角**必须 Canvas 画**（7×4dp），不能用 `▾`：10sp 的 ▾ 在 440dpi 上只有约 4px，
实机上糊成一个脏点。

⚠️ 归档之后要在项目卡里补一句「已归档 · 全部条目均已提交」。**凭空消失比占位更糟** ——
用户会以为项目被删了。

### 5.8 功能入口按「打开频率」归置，不按「像不像设置」

自动记账曾经被收进「我的 → 更多设置」，理由是它"属于设置"。结果：
它是每天在后台自己干活、偶尔判错一次的功能，而「捕获日志」又嵌在它里面 ——
**判错的时候要翻四步**，用户就不看了，下次还是不知道为什么。

| 判据 | 结论 |
|---|---|
| 每天/每次判错都会打开 | 必须在**一级页**（我的首页） |
| 调一次、长期不动 | 二级页（更多设置） |
| 出问题时第一反应要找 | 一级页，且**旁边要有一行"最近发生了什么"** |

⚠️ **诊断入口旁边必须给一行结论**。只有"查看日志"按钮时，用户仍要先点开、滚动、比对时间。
现在卡里直接写「最近一次 · 已入账 / 未入账 + 标题 + 金额或原因 + 时间」——
八成的问题看一眼这行就够，日志留给"这行仍解释不了"的情况。

## 6. 禁止项

- 磨砂 / 亚克力 / 高斯模糊（玻璃**不改变背景清晰度**，只改变背景在边缘的位置）
- 厚卡（膜 > 25%）、硬阴影、三道同心圆角矩形冒充投影
- 高饱和、强发光、彩虹渐变边框、假极光
- 脏灰 / 惨白底（顶 > 30% 白、底 < L\*88 都会到这两头）
- 「收起」之后又拿另一块内容占位
- 一屏里同一份数据出现两遍（**也包括"标题写一遍、卡里再写一遍"**）
- **有当前对象却用栏目名当大标题**（明细页写「明细」而不写账本名）
- 表外字号（11/13/15/17/20/24/30/44 之外的任何值，含 Int 形参）
- 浮层复用底栏那档 92% 透明度（菜单下面是文字，会透成重影）
- **悬浮球压住列表**（主行动必须沉进底栏或顶栏，不许浮在内容之上）
- **把动作格塞进导航胶囊**（胶囊只放 Tab；动作要在胶囊**外**独立成颗）
- **加号撑满圆钮**（十字占直径 > 35% 就显突兀）
- **主行动键用实心色块**（"更重要"不能用"更不透明"表达；见 §5.3）
- **让动态取色去改 `background` / 语义色 / 玻璃 alpha**（会同时击穿 §1 的三条门槛）
- **把日常要查的功能塞进二级页**（判据是打开频率，不是"像不像设置"）
- 归档/隐藏一条数据时**不给"它去哪了"的说明**（凭空消失比占位更糟）
- **双栏时底栏骑在分栏缝上**（停右栏或左栏，不许跨缝）
- 调试状态条留在正式界面（`608 × 859 dp · 外屏 · 单栏` 那类，v13.6 已撤）
- 折叠时**换内容/跳变**（只许同一颗字缩号、同一行字让位）
- 吸顶卡与内容之间留缝（那道缝会露出被切掉一半的上一行文字）
